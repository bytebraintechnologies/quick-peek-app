# Privacy

Quick Peek processes previewed files locally on the Windows device. It does not upload file contents
to Bytebrain for preview generation.

The application does not include advertising or application-usage telemetry. The standalone build
contacts GitHub to check the official release feed for updates. Network links are opened only for
features that visibly request them, such as opening a repository or map location in the browser.

Application preferences, recent-item state, caches, and diagnostic logs are stored locally. They can
contain file paths or other metadata from files the user chose to preview. Users should review such
data before attaching it to a public support issue.

Microsoft Store, Windows, WebView2, preview handlers, and external applications used to open links
operate under their respective privacy terms.

This summary applies to the current Quick Peek application. Material changes will be documented in
this file and in the relevant release notes.
