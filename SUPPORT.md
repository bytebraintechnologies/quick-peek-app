# Support

Use [GitHub Issues](https://github.com/bytebraintechnologies/quick-peek-app/issues) for reproducible
bugs and feature requests that can be discussed publicly.

Before opening an issue:

1. Install the latest release.
2. Check existing issues for the same behavior.
3. Include the Quick Peek version, Windows version, installation type, file format, and reproduction
   steps.
4. Remove confidential information from logs, screenshots, and sample files.

For security problems, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.

This repository distributes compiled releases. Source-code requests and pull requests implementing
application changes cannot be accepted here.
